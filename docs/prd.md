#### **1. 产品概述**

- **应用名称:** 启航者 (Voyager)
- **版本:** 1.0
- **愿景:** 打造一个以AI助手为核心的个人成长赋能工具，将自我提升过程游戏化，提供持续的正向反馈和个性化引导。

#### **2. 功能需求**

**2.1. 主界面 (Dashboard)**

- **布局:** 左侧为玩家状态面板，右侧为任务/愿望面板。
- **核心元素:**
  - 等级 (LV) 与 经验条 (XP)。
  - 五维属性雷达图 (知识, 表达, 共情, 毅力, 勇气)。
  - **AI助手“凯”交互入口:** 一个悬浮、有呼吸感动画的球体。点击后展开对话界面。

**2.2. AI助手“凯” (Kai, The AI Assistant)**

- **定位:** 应用的核心交互中枢和智能引擎。
- **核心行为能力:**
  - **任务拆解:** 用户可通过对话，让“凯”将一个宏大目标（如“学习编程”）分解为一系列具体的、可执行的子任务，并自动添加到任务列表中。
  - **主动关怀与建议:** “凯”应能从用户的日常聊天中感知其情绪状态（如疲惫、焦虑），并主动推荐有益的放松或整理类小任务。
  - **任务执行支持:** 用户在执行任何任务时，可向“凯”请求帮助。“凯”应能提供相关的学习资源、解决思路或鼓励话语。
  - **智能奖励评判:** 用户完成任务并提交“心得体会”后，“凯”将分析该体会，并根据其中体现的努力、学习和挑战，自动计算并发放经验值(XP)和属性点奖励，同时给予个性化的鼓励评语。

**2.3. 任务与愿望系统 (Quest & Wish System)**

- **任务:** 以卡片形式展示，分为主线、支线、每日。用户可手动添加，也可由“凯”创建。
- **愿望:** 用户的长期目标，与等级挂钩。达到特定等级后自动解锁。

**2.4. 设置 (Settings)**

- **入口:** 主窗口菜单栏 `文件 -> 设置`。
- **功能:**
  - 弹出一个独立的设置对话框。
  - **AI配置:** 必须提供一个输入框，让用户可以编辑和保存自己的大模型API Key。为保护隐私，输入框应默认为密码模式。
  - **数据管理:** 提供数据导出/导入功能。

#### **3. 非功能需求**

- **技术栈:** Python 3, PyQt5。
- **数据存储:**
  - **用户数据 (`voyager.db`):** 使用SQLite存储等级、任务、属性等成长数据。
  - **配置数据 (`config.json`):** 使用JSON文件存储API Key等非成长性的应用配置。
- **隐私:** 所有数据均为本地存储，确保用户隐私。
